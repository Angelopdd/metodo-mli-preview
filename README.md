# Método M.L.I. — versão demonstrativa

Protótipo visual de página de vendas, feito para aprovação do cliente.

- HTML, CSS e JS puros, sem build.
- Botões demonstrativos: não há checkout, backend nem integrações.
- Vídeo, foto oficial e comprovantes são placeholders identificados na página.
- Marcada com `noindex`: não deve aparecer em buscadores.
